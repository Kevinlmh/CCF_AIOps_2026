# v4 第三阶段：状态发现与候选事件

用户授权继续已确认的第三阶段：特征矩阵、稳健参考尺度、轻量聚类、规则候选事件及小规模实验。延续当前 v4 分支；不重新请求已授权任务的确认。保留已有 data/output/outputs/submit.py，仅创建独立结果目录。

## 输入与边界

输入为第二阶段完整发布目录中的 windows.jsonl 与 summary.json，必须显式指定同一 batch。允许 prefix_sample，但继承其范围限制；完整扫描不意味着正常数据。第一批解压或重新下载不作为本阶段前提。不读取旧特征库、标签、提交脚本；不调用 LLM，不输出官方故障分类。

Python >=3.10，仅标准库。临时 SQLite 按 group/start/window_id 排序，逐组拟合与评分，避免全量矩阵驻留内存。重复 window_id、混合批次、非有限 JSON、无时区时间、重叠窗口、错误 summary 计数应拒绝，失败不发布结果。输出须是输入目录之外的新路径。

## 矩阵与参考尺度

group = batch/source/view/role/entity_id/完整 dimensions，保持原始序列粒度。不同网元、接口、路由 peer、业务目标及辅助身份分别学习；此阶段不跨视角拼接，后续事件确认时关联证据。

每个 gauge 选择 mean，counter 选择 rate_mean，interval_count 选择 sum；binary/state_code 选择 last 类别值，不把状态码均值作为连续量。未知语义字段排除。非负数量/速率用 log1p，比例/百分比/连续时间保持原尺度。保留原值、转换、单位及 inferred 状态。坏值/冲突或 counter 中断的指标被掩码，不填零；部分缺失记录只保留可用特征。窗口共享身份/维度冲突阻止学习，辅助网元正常保留 candidate=false。

参考范围可显式指定 [reference_start, reference_end)，要求窗口完整包含在区间内；未指定时为同批次离线无监督拟合，明确非已知正常、非在线因果评估。每特征最少 12 个可用参考点（可配置），最多 128 个特征、256 个参考样本。numeric 中位数/MAD 为稳健尺度；MAD=0 时依次使用 IQR/2、max(abs(median)*0.01,1e-6)，记录 fallback。这些尺度与阈值是实验参数，不是故障概率。categorical 使用最多 16 个值的参考频数，记录未见类别。

## 聚类与评分

固定种子参考向量蓄水池最多 64 点，deterministic k-medoids，最多 k=3（可配置，不固定两个状态）、6 次迭代。数值按稳健尺度标准化，聚类距离数值部分截到 ±20（仅距离表示，原值与统计偏离不截断），类别使用 0/1 不一致；共同有效特征占全部有效模型特征至少 0.5，RMS 距离按共同特征数归一化，缺失不补值。无法比较的点保留未分配状态。

记录最近 medoid、距离、参考簇占比、统计最大偏离、未见类别、有效覆盖与状态变化。簇没有正常/故障标签。候选触发：统计偏离 >=6、聚类距离 >=3、簇参考占比 <=0.1、未见类别或领域规则；支持 statistics/cluster/hybrid 三种实验模式。状态变化单独记录，不自动触发事件。

## 规则与候选事件

规则只输出观测事实：窗口内 min/last 为零的 scrape_up、bgp_peer_up/ipv6_route_exists、接口 drop/error rate>0、业务失败/超时计数增长、路由变更计数增长、类别状态变化、FRR 警告/错误级别。二值窗口内/相邻窗口变化保留为信息线索，单独恢复不延长不可用事件；state_code 变化作为候选线索。计数器下降/长间隔等质量线索独立记录，不单独生成故障候选。规则不赋予根因或官方类别。

每原始序列内连续有触发的相邻窗口合并；正常窗口、缺失时间间隔均终止连续事件，不假定间隔内持续异常。事件含候选身份、source/view/完整 dimensions、观测时间、触发种类、峰值分数、最多 16 条原始引用和 64 个 window_id，截断显式标记，不预设事件数量或最大时长。LLM 后续负责确认事件及关联不同序列。

## 产物与验收

matrix.jsonl、models.jsonl、states.jsonl、events.jsonl、summary.json、report.md；summary 最后发布。继承输入采样、语义与时区状态，记录参考选择、阈值、容量、不可评分原因、每来源数量及 statistics/cluster/rule 触发数，便于消融。输入目录路径与摘要用于复现，不读取原始 CSV 即可运行。

测试必须覆盖：粒度隔离/类别与 counter 特征、缺失与 unknown、仅参考区间拟合、常量尺度、稀疏参考、混合距离/不足重叠、确定性/少于 k 个状态、规则与质量分离、正常/时间间隔终止事件、跨文件乱序/重复/混批/输出保护。独立合成保留段包含已知尖峰与状态变更，分别量化统计与聚类响应；公开样例及第二批前缀实测不宣称诊断准确率。
