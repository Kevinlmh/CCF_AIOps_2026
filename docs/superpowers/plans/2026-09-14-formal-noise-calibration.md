# 正式数据噪声校准实施计划

**目标：** 修复正式数据中工作负载波动触发海量伪事件、分类偏置和跨城市候选污染，同时保持七源完整读取及公开样例回归。

1. 先为观测角色、事件门控、候选城市和分类信号补充失败测试。
2. 扩展统一观测、指标语义和 checkpoint，使 `trigger/support/detect=false` 贯穿流式检测。
3. 以合格 trigger 能量开启事件，窗口内保留 support，增加可配置的 20 分钟峰值抑制并校准置信度。
4. 根因候选仅保留事件涉及城市；中性业务字段不得产生服务故障信号，support 分类权重降低。
5. 改善推理日志能量摘要，模型版本升级为 1.2，更新运行文档中的缓存名称。
6. 运行针对性测试、全量测试、公开 sample 评测，然后用新文件名完整重跑成都七源并审计结果。
