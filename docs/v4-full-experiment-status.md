## 本轮采用的流程

原始 CSV → 质量统计 → 多粒度分钟窗口 → 稳健统计、轻量聚类和领域规则 → 候选事件与证据 → LLM 确认 → 相互独立的定位与分类 → LLM 一致性复核 → 程序重验 → 官方 JSONL。

主实验采用最初设计的独立角色流程：`mode=independent`、`review_mode=llm`。确认、定位、分类及复核均实际调用同一个本地 Qwen3-8B-AWQ。最终预测由通过原有证据、窗口归属、合法类别和复核约束的结果导出。

LLM 能在已有候选窗口内确认、拒绝或拆分事件，并判断根因和类别。它不能补回上游未准入的窗口，也不能把分钟观测边界变成已知物理故障起止。原始统计与聚类仍由程序完成。

## 接入与不接入模型的实验差异

| 实验 | 输入和候选 | 事件与预测 | 根因与类别 | 能否官方评分 |
|---|---|---|---|---|
| 离线发现 `discovery_only` | 实际解析 CSV，生成全部窗口、候选与证据 | 停在证据，预测为空 | 未执行诊断 | 不产生诊断分数 |
| 无 LLM 资源规则对照 | 固定相同封存候选 | 用受支持资源规则生成区间 | 本机根因；仅 CPU、内存、磁盘 I/O、磁盘空间几类 | 可对这三个资源样例评分；不是覆盖 32 类的完整诊断器 |
| 原架构 LLM 主实验 | 可重新解析全量 CSV，或明确固定同一封存输入 | LLM 确认/拒绝/暂缓/拆分，故障数量和时段可能改变 | 独立定位、分类及复核后导出 | 有公开真值时可评分；隐藏集需比赛平台 |
| `review_mode=program_only` | 仍经过模型确认、定位和分类 | 只取消语义复核 | 其余角色仍调用 LLM | 属于复核消融，不能称为无模型实验 |

公平对照应固定输入范围、候选生产版本和阈值，再分别执行规则对照和 LLM 诊断。无模型资源对照不覆盖网络与服务故障，不应把它与完整类别范围的隐藏集结果直接比较。

使用本轮重新扫描、封存的相同样例候选，资源规则得分 93.3103，LLM 版 86.6436。两者均 TP=3、FP=1、FN=0；规则对照三个真实事件小类正确，模型把内存与磁盘 I/O 判为 CPU，扣掉了小类分。它说明已有分类偏差，不能据三个开发样例推断隐藏集成绩。

## 本轮查明并修复的非模型问题

| 问题 | 影响 | 修复 |
|---|---|---|
| 紧凑证据只保留 `::mean` | 业务计数器的 `::rate_mean`、NetFlow 数量和 `::sum`、路由状态 `::last` 在默认输入中缺失 | 保留实际特征统计类型、完整原生维度和计数器重置/间断质量；数值不填零，单位与统计名称保留 |
| 接口与 peer 维度未交付 | 角色无法从默认输入区分哪一个接口或邻居发生变化 | 紧凑观察保留 `dimensions`，查询与实际角色记录使用同一投影 |
| 计数器速率沿用原始数量单位 | `::rate_mean` 已经是每秒差分，却仍标成 count/bytes/seconds | 矩阵和模型投影分别标注原始数量单位及每秒速率单位；旧封存输入仅在只读展示时纠正单位，不改数值或原文件；未知单位仍未知 |
| OSPF 非 Full 线索被保守准入压掉 | 曾观测 Full 后出现非 Full 状态，仍无候选 | 明确保留协议状态线索；支持单窗口及同分钟内恢复；没有 Full 观测的稳定非 Full 状态仍作为上下文 |
| 初始资源参考未校验物理范围 | 负 CPU/load 或可用内存比例大于 1 可使后续普通窗口被当成相对压力 | 初始参考仅采用有限、范围合法的值；原始异常值仍保留，不裁剪为合法数据 |
| 分组 schema 重复枚举全部组号 | 100 窗约 75 KB，200 窗约 310 KB，长事件消耗巨大提示预算 | 大集合使用线性规模的组号语法；本地继续校验号段、非空分组、连续区间和每窗恰好一次归属 |
| 长运行缺少阶段复用与可见进度 | 中断后重扫原始 CSV，无法区分慢解析与卡住 | 每个成功阶段写校验过的 checkpoint；续跑检查配置、代码、原始清单和产物哈希；输出阶段、行数、模型调用及磁盘剩余 |

磁盘预留异常采用独立的运行控制类型，避免被 CSV 解析层当成坏记录吞掉并发布不完整的扫描阶段；这一中途低空间路径已有回归测试。

本地模型实际工具调用已验证新的组号正则语法可被 vLLM 接受。小样例的组号枚举协议保持原样。

最终代码在 Mac 与服务器均通过 **425 项测试**；最新复验分别用时 29.47 秒和 68.91 秒，两端程序代码指纹一致。测试覆盖压缩存储、流式 NetFlow、保守候选、角色隔离、引用与窗口归属、速率单位及阶段续跑。测试通过说明已检查的实现行为成立，不说明隐藏数据上的检测或分类准确率已达标。

本次没有把这些修复称为所有漏洞都已解决。仍需验证：全区间参考对长期故障的吸收、首个观测已异常时的相对参考、短时/仅日志或流量故障的召回、多节点伴随异常重复预测，以及超长 manifest 和模型 token 预算。线性 schema 缩小了开销，未保证任意长度事件都能放入 32,768 token。
